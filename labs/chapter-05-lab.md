# Chapter 5 Lab: Domain 5: Machine Learning Fundamentals

**Estimated time:** 25 minutes

## Exercise

Using scikit-learn, train a DecisionTreeClassifier on a sample dataset with a train/test split, then vary max_depth to observe and plot the transition from underfitting to overfitting.

## Key takeaway

Correctly splitting data and recognizing overfitting vs underfitting is the core diagnostic skill tested throughout ML Fundamentals.
