# Chapter 8 Lab: Domain 8: NLP, Transformers, and LLM Fundamentals

**Estimated time:** 25 minutes

## Exercise

Use the Hugging Face transformers library to tokenize sample text, inspect token counts, generate embeddings, and run a pretrained sentiment-analysis pipeline end to end.

## Key takeaway

Tokenization, self-attention, and context window limits are the practical LLM mechanics a developer must understand to use transformer models correctly from code.
