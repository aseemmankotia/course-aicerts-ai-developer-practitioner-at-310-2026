# Chapter 7 Lab: Domain 7: Deep Learning and Computer Vision Basics

**Estimated time:** 30 minutes

## Exercise

In PyTorch, build and train a small feedforward neural network on a toy image dataset, then load a pretrained CNN (e.g. ResNet) and fine-tune only its final layer for a new image classification task via transfer learning.

## Key takeaway

CNN basics and transfer learning let developers apply deep learning to vision tasks efficiently without training massive networks from scratch.
