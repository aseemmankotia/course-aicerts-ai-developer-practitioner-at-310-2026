# Chapter 2 Lab: Domain 2: Python Programming for AI

**Estimated time:** 20 minutes

## Exercise

Write a Python script that loads a CSV with pandas, computes column statistics using vectorized numpy operations, then times the same computation with an explicit for-loop to compare performance.

## Key takeaway

Working-level numpy and pandas fluency — especially vectorization over loops — is a core, heavily tested AT-310 developer skill.
