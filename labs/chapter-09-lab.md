# Chapter 9 Lab: Domain 9: Generative and Multimodal AI Application Development

**Estimated time:** 25 minutes

## Exercise

Write a Python script that calls an LLM API with a defined JSON output schema for a simple feature (e.g. a recipe generator), parse and validate the structured response, and experiment with temperature settings to observe output variability.

## Key takeaway

Building reliable GenAI features means pairing good prompting with structured output validation and awareness of generation parameters.
