# Chapter 11 Lab: Domain 11: Simple AI Agents, APIs, and Deployment

**Estimated time:** 30 minutes

## Exercise

Wrap an LLM call or trained model in a FastAPI endpoint using Pydantic models for request and response validation, write a Dockerfile to containerize it, build and run the container locally, and test it with curl.

## Key takeaway

Turning a model into a reliable service requires validated FastAPI endpoints, correct sync/async design, and Docker containerization.
