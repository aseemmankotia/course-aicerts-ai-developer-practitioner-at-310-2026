# Chapter 3 Lab: Domain 3: Data Handling and Visualization

**Estimated time:** 25 minutes

## Exercise

Load a messy sample dataset with pandas, handle missing values, one-hot encode categorical columns, scale numeric features, then produce a histogram, a box plot, and a correlation heatmap with matplotlib/seaborn.

## Key takeaway

Clean, correctly encoded, and well-visualized data is the foundation every later ML step depends on — and the exam tests the reasoning behind each choice.
