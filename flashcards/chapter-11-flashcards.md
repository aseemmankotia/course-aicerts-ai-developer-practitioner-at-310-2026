## Chapter 11: Domain 11: Simple AI Agents, APIs, and Deployment — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | What are the three steps of the basic AI agent loop? | Plan → Act → Observe (then repeat). Plan: decide next action/tool. Act: execute the tool/function call. Observe: evaluate the result to inform the next plan. Exam tip: observe always follows act, never precedes it. |
| 2 | FastAPI: how do you define a request body validated by Pydantic? | Create `class RequestModel(BaseModel): field: type`, then type-hint it as a parameter: `def predict(req: RequestModel):`. Exam tip: FastAPI auto-generates OpenAPI docs and returns HTTP 422 on validation failure. |
| 3 | Pydantic: how to constrain a float field to range 0–2 with default 0.7? | `temperature: float = Field(0.7, ge=0, le=2)`. Exam tip: ge/le = inclusive bounds, gt/lt = exclusive bounds. |
| 4 | When does FastAPI run a sync `def` endpoint in a threadpool automatically? | Always — FastAPI runs synchronous `def` path operations in an external threadpool automatically so blocking code doesn't freeze the event loop. `async def` endpoints run directly on the event loop and must avoid blocking calls. |
| 5 | What happens if you call a blocking function (e.g., `requests.get()`) inside an `async def` FastAPI endpoint without offloading it? | It blocks the entire event loop, stalling ALL concurrent requests on that worker. Exam tip: use `httpx.AsyncClient` with `await`, or offload via `run_in_threadpool`/`asyncio.to_thread`. |
| 6 | Docker: RUN vs CMD — when does each execute? | RUN executes during image BUILD time (e.g., installing packages). CMD (or ENTRYPOINT) executes when the CONTAINER STARTS, defining the default process. Exam tip: starting uvicorn belongs in CMD, never RUN. |
| 7 | Correct Dockerfile CMD to run a FastAPI app with Uvicorn on port 8000 for all interfaces? | `CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]` (exec form). Exam tip: exec/JSON-array form handles OS signals correctly for graceful shutdown; shell form does not. |
| 8 | Why use a slim base image (e.g., python:3.12-slim) for an AI service Docker container? | Reduces image size and attack surface versus full images like `python:3.12` or `ubuntu`. Exam tip: combine with a multi-stage build to exclude build-only tools (compilers) from the final image. |
| 9 | Pydantic request model vs plain dict for FastAPI request validation — exam-preferred approach? | Always use a Pydantic `BaseModel`. It gives type coercion, constraint validation via `Field`, automatic HTTP 422 errors, and auto-generated OpenAPI schema docs. Plain dicts/TypedDicts give no runtime validation. |
| 10 | Sync (`def`) vs async (`async def`) FastAPI endpoint — when to choose async? | Choose `async def` when all I/O inside uses `await`-able async libraries (e.g., `httpx.AsyncClient`, async DB drivers). Choose plain `def` for blocking/sync libraries (e.g., `requests`, CPU-bound model inference) — FastAPI auto-offloads these to a threadpool. |
| 11 | What does 'tool calling' mean in a basic AI agent loop? | The model/agent decides to invoke an external function (e.g., calculator, search API) with structured arguments during the 'Act' step, then receives output to 'Observe'. Exam tip: tool calling requires a defined schema (name, description, parameters) the model chooses from. |
| 12 | Scaling: why does latency increase when a synchronous model-inference call blocks the FastAPI event loop under concurrent load? | A blocked event loop (async def endpoint with no offloading) can't process other requests, serializing all concurrent calls on that worker and increasing tail latency. Fix: offload via threadpool/`asyncio.to_thread`, or run multiple Uvicorn worker processes (`--workers`). |
