## Chapter 3: Domain 3: Data Handling and Visualization — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | Rule of thumb for missing data: drop column vs impute? | >~40-50% missing in a column → consider dropping it; <5% missing → safe to impute (mean/median/mode) or drop the few affected rows. Exam tip: the exam tests threshold-based judgment, not memorized exact cutoffs. |
| 2 | Label encoding vs one-hot encoding — when to use which? | Label encoding: ordinal categories only (e.g., 'low/medium/high') — preserves order as integers. One-hot encoding: nominal categories (e.g., 'red/blue/green') — creates binary columns, avoiding a false ordinal relationship. Exam tip: nominal + label encoding is the classic wrong-answer trap. |
| 3 | Standardization vs Normalization — formulas and outputs? | Standardization (StandardScaler): (x-mean)/std → mean=0, std=1, unbounded. Normalization (MinMaxScaler): (x-min)/(max-min) → bounded [0,1] by default. Exam tip: use standardization for Gaussian-like/outlier-prone data; normalization when a bounded range is required. |
| 4 | Pandas function to load data directly from a SQL database connection? | pd.read_sql(query, connection) — also pd.read_sql_query() and pd.read_sql_table(). Requires a DB connection object (e.g., sqlite3.connect() or a SQLAlchemy engine). Exam tip: read_sql() is the umbrella function accepting either a query string or a table name. |
| 5 | Function to flatten nested JSON dict structures into flat DataFrame columns? | pd.json_normalize(data) — converts nested keys into dot-notation columns (e.g., 'address.city'). Exam tip: pd.read_json() alone does NOT flatten nested objects. |
| 6 | Pandas one-hot encoding function and the parameter to avoid the dummy variable trap? | pd.get_dummies(df['col'], drop_first=True) — drop_first removes one category's column to prevent perfect multicollinearity in linear models. |
| 7 | Standard EDA workflow order (high level)? | 1) Load data 2) Inspect shape/dtypes/head() 3) Detect missing values (isnull().sum()) 4) Detect outliers (box plot/IQR) 5) Visualize distributions (histograms) 6) Check correlations (heatmap) 7) Encode/scale features. Exam tip: scenarios often ask which step comes NEXT in this sequence. |
| 8 | Decision pattern: when to DROP rows vs IMPUTE for missing data? | Drop rows: missingness is small (a few %), random (MCAR), and the dataset is large. Impute: the column must be kept, missingness isn't random, or dropping loses too much data. Exam tip: 'random and small %' → drop; 'systematic or large %' → impute or drop the column. |
| 9 | Standard statistical rule for flagging outliers using IQR? | A value is flagged as an outlier if it falls below Q1 − 1.5×IQR or above Q3 + 1.5×IQR, where IQR = Q3 − Q1. Exam tip: this is the same rule box plots use to draw whiskers and mark outlier points. |
| 10 | Which plot: single-variable distribution vs two-variable relationship vs multi-variable correlation? | Single variable distribution → histogram or box plot. Two continuous variables' relationship → scatter plot. Many numeric variables' pairwise correlation → heatmap. Exam tip: match the data question's wording to the correct chart type. |
| 11 | Pandas commands to detect and count missing values per column? | df.isnull().sum() or df.isna().sum() — returns missing count per column. df.isnull().mean() gives the proportion missing. Exam tip: isna() and isnull() are aliases and function identically. |
| 12 | StandardScaler output mean/std vs MinMaxScaler output range? | StandardScaler → mean=0, std=1 (unbounded, can be negative). MinMaxScaler → default range [0,1], non-negative by default. Exam tip: if the question says 'bound features between 0 and 1,' the answer is MinMaxScaler, not StandardScaler. |
